Project overview

This research project focused on control algorithms for hydraulic vibration-damping fixtures. The work included embedded PID control, Siemens PLC programming, and mechanical fixture design.

My contributions

  • Programmed an Arduino PID algorithm to regulate motor rotation.
  • Programmed Siemens PLC PID control to adjust hydraulic fixture force using pressure feedback.
  • Designed mechanical fixtures and coordinated component procurement with suppliers.

Technical approach

Hydraulic pressure serves as feedback for regulating fixture force. Siemens PLC and Arduino programming support the control functions, alongside the design of the mechanical fixture system.
