# Research pages

Edit the corresponding HTML file to update project text:

- 3D Motion Control of Microrobots: `microrobot-control.html`
- Flight Simulator Chair: `flight-simulator-chair.html`
- Thumb Rehabilitation Robot: `thumb-rehabilitation.html`
- Hydraulic Vibration Damping: `hydraulic-vibration-damping.html`

Each page contains Overview, My contributions, Technical approach, Images, and Video sections. Comments identify where to add further text, photographs, and native MP4 video players. Image links open the full illustration. Replace the existing figure image with your photograph and update its caption. Duplicate a figure for extra images.

For video, upload the MP4 mentioned in the HTML comment, then replace the `video-empty` block with the commented `video` element. Do not leave the video inside an HTML comment. Update the filename if different. External hosted videos can use an embed instead. Files uploaded using the GitHub web interface must be under its upload size limit.

The homepage cards are in `index.html`. Their summaries are separate from the detail-page text. All files are in the repository root; preserve existing file names when replacing media. The cards are ordered by project start date, newest first. Card and detail-page styling is in `projects.css`; shared site styles remain in `styles.css`.
